Engineering Specification — v0.18.019

Architecture

  • Ingest: GIBS (IMERG visuals), IMERG quantitative; SMAP L3/L4; LHASA 2.x; USGS 00060; NWS CAP/IPAWS.
  • Catalogs: STAC; rasters as COG; serverless via PMTiles.
  • Compute: fractional memory (Caputo), DI/envelopes, online Hedge consensus.
  • Streaming: SSE; Push: Web Push (VAPID); Transport: QUIC/HTTP-3, MPTCP optional; FEC on p99>1s.
  • Integrity: CRC-32 + Reed–Solomon; Provenance: PROV-O bundle (FART).
